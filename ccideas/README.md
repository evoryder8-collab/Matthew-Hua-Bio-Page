# ccideas

`matthewhua.ch/ccideas` shows Constantin Barbu's CB Viral Content Hub in a full-screen frame. The hub is hosted on
GitHub Pages: https://evoryder8-collab.github.io/cb-viral-content-hub/ (source: `evoryder8-collab/cb-viral-content-hub`).

- Only `index.html` lives here, and it is hand-written. It is not generated by `npm run build`, not linked from
  Matthew's pages and not in `sitemap.xml` (`noindex, nofollow`).
- Hub updates appear here automatically: nothing in this folder needs to change when the hub changes.
- Section links work: `/ccideas#favourites` (All-time favourites), `/ccideas#halloffame`, `/ccideas#hooks`.
  The hub reports its current section back (hash only, origin-checked), so the address bar stays shareable.
